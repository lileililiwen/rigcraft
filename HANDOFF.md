# Project Handoff

## Current state

current_spec: none

All five implementation packages in `ROADMAP.md` are implemented, archived and committed on `main`, and `openspec list` reports no active change. The `real-catalog-seed-and-import` change is implemented and archived: the shipped sample is now one sourced AM5 build, optional `source`/`sourceUrl` columns carry catalog provenance through preview, commit and snapshot, the OpenDB converter is documented and tested, and the licence position is recorded. The `correctness-audit-remediation` change is also implemented and archived: snapshot totals use checked arithmetic and reject overflow, diagnosis parts with no evaluated rule have an explicit unverified group, Markdown export escapes operator text, unknown static/metadata paths 404, extractor failures use the JSON error envelope, `/diagnose` keeps a stable 1–5 skeleton, currency is normalized case-insensitively, and every visible timestamp is ISO 8601 UTC. The diagnosis page at `/diagnose` takes parts matched from a snapshot or entered by hand, reports must-replace / should-upgrade / keep / unverified with the rule evidence and cost, and labels a replacement plan validated only when the same compatibility engine accepts the whole upgraded build. Deployment remains disabled (`deployment.deployable: false`); no licensed hardware catalog, live pricing or performance evidence is bundled.
