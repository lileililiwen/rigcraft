# Project Handoff

## Current state

current_spec: none

`requirement.md` is the product baseline. Inventory import and provenance is implemented, archived and tested: `/inventory` previews UTF-8 CSV, reports field-coded row errors, requires explicit duplicate decisions, commits immutable SQLite snapshots with per-field provenance, and creates new revisions for corrections. Evidence-backed compatibility is implemented and archived: `/builds/check` returns compatible, incompatible or unknown per versioned rule with compared values, provenance, specific unknown follow-ups, and revision-bound persisted reports that become stale. Budget- and stock-constrained recommendation is implemented and archived: `/recommend` searches one snapshot deterministically within a stated work limit, returns up to three complete compatible options with reasons, exclusions and comparison, explains the binding budget, stock or compatibility constraint when there is none, and exports versioned JSON or a Markdown plan. BYOK planning and build diagnosis remain unimplemented packages. Deployment remains disabled.
